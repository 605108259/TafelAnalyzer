## 2. 版本号管理

客户端版本号定义在：

```text
src/core/version.py
```

关键字段：

```python
APP_VERSION = "1.0.5"
UPDATE_MANIFEST_URL = "http://107.174.62.19/tafsq/update.json"
```

安装包版本号定义在：

```text
TafelAnalyzer_Setup.iss
```

关键字段：

```iss
#define MyAppVersion "1.0.5"
#define MyAppSourceDir "dist-1.0.5\TAFSQ"
OutputBaseFilename=TAFSQ-1.0.5-setup
```

发布新版本时，至少需要同步修改：

1. `src/core/version.py` 的 `APP_VERSION`
2. `TafelAnalyzer_Setup.iss` 的 `MyAppVersion`
3. `TafelAnalyzer_Setup.iss` 的 `MyAppSourceDir`
4. `TafelAnalyzer_Setup.iss` 的 `OutputBaseFilename`
5. VPS 上的 `update.json`

## 3. 客户端自动更新流程

自动更新逻辑位于：

```text
src/ui/updater.py
```

启动入口在：

```text
src/ui/app.py
```

流程：

1. 软件启动后延迟约 1.2 秒后台检查更新。
2. 请求 `UPDATE_MANIFEST_URL`。
3. 读取远端 JSON 中的 `version`、`url`、`sha256`、`size`。
4. 使用 `core.version.is_newer_version()` 比较远端版本和本地版本。
5. 如果远端版本更高，显示“发现新版本”弹窗。
6. 用户点击“立即更新”。
7. 下载远端安装包到临时目录：

   ```text
   %TEMP%\TAFSQ-update\
   ```

8. 显示下载进度。
9. 如果 `update.json` 提供了 `sha256`，下载完成后校验文件。
10. 生成临时脚本：

    ```text
    %TEMP%\TAFSQ-update\run-update.cmd
    ```

11. 通过 `cmd.exe /c run-update.cmd` 启动更新脚本。
12. 当前程序退出。
13. 脚本等待 2 秒后运行安装包：

    ```text
    /SILENT /SUPPRESSMSGBOXES /NORESTART /CLOSEAPPLICATIONS
    ```

14. 安装成功后重新启动当前 exe。

注意：

- 如果安装目录在 `Program Files`，Windows 可能弹出 UAC。
- UAC 是系统权限控制，不能由普通桌面程序无感绕过。
- 如果某个版本启动即崩溃，则该版本无法执行自动更新，用户需要手动安装修复版。

## 4. `update.json` 格式

示例：

```json
{
  "version": "1.0.5",
  "url": "http://107.174.62.19/tafsq/TAFSQ-1.0.5-setup.exe",
  "filename": "TAFSQ-1.0.5-setup.exe",
  "sha256": "d96468d86357cb7ef20825bbfaae40a51be101d3532ca43e500cdfee11255fc2",
  "size": 92837472,
  "mandatory": false,
  "notes": "Improve side panel responsiveness, tolerate non-standard TDMS channels, and support saved fitting parameter defaults."
}
```

字段说明：

- `version`：远端最新版本号。
- `url`：安装包下载地址。
- `filename`：下载到临时目录时使用的文件名。
- `sha256`：安装包 SHA256，用于完整性校验。
- `size`：安装包大小，客户端用于显示进度。
- `mandatory`：是否标记为必须更新；当前只是提示文案，不强制阻断旧版本使用。
- `notes`：更新说明。

## 5. 本地构建流程

### 5.1 运行测试

```powershell
python -m compileall src tests scripts
python -m pytest
```

### 5.2 构建 PyInstaller 目录

必须包含 `--paths src`。

如果不加 `--paths src`，打包后的 `TAFSQ.exe` 可能启动失败并报：

```text
ModuleNotFoundError: No module named 'ui'
```

示例：

```powershell
python -m PyInstaller `
  --noconfirm `
  --distpath dist-1.0.5 `
  --workpath build-1.0.5 `
  TAFSQ.spec
```

### 5.3 验证打包后的 exe

可用 offscreen 模式做基础启动检查：

```powershell
$env:QT_QPA_PLATFORM='offscreen'
$p = Start-Process -FilePath (Resolve-Path 'dist-1.0.5\TAFSQ\TAFSQ.exe') -PassThru -WindowStyle Hidden
Start-Sleep -Seconds 5
if ($p.HasExited) { "exited $($p.ExitCode)" } else { "running"; Stop-Process -Id $p.Id -Force }
```

输出 `running` 表示至少完成了应用启动。

### 5.4 编译 Inno Setup 安装包

Inno Setup Compiler 位置：

```text
C:\Program Files (x86)\Inno Setup 6\ISCC.exe
```

编译：

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" TafelAnalyzer_Setup.iss
```

输出示例：

```text
installer_output\TAFSQ-1.0.5-setup.exe
```

## 6. 生成更新清单

使用脚本：

```text
scripts/make_update_manifest.py
```

示例：

```powershell
python scripts\make_update_manifest.py `
  --version 1.0.5 `
  --artifact installer_output\TAFSQ-1.0.5-setup.exe `
  --base-url http://107.174.62.19/tafsq `
  --notes "Improve side panel responsiveness, tolerate non-standard TDMS channels, and support saved fitting parameter defaults." `
  --output release\update.json
```

脚本会自动计算安装包 SHA256 和文件大小。

## 9. 常见问题

### 9.1 安装后提示 `No module named 'ui'`

原因：

PyInstaller 构建时没有加入 `src` 搜索路径。

修复：

```powershell
python -m PyInstaller --paths src ...
```

### 9.2 自动更新没有弹窗

可能原因：

- 本地版本已经等于或高于远端版本。
- 无法访问 `update.json`。
- 当前版本启动即崩溃，无法执行自动更新逻辑。

检查：

```powershell
Invoke-WebRequest -UseBasicParsing http://107.174.62.19/tafsq/update.json
```

### 9.3 一键更新没有完全无感

如果软件安装在 `Program Files`，安装器写入目录时需要管理员权限，Windows 会弹 UAC。这是正常行为。

### 9.4 下载后校验失败

原因通常是：

- 安装包上传不完整。
- `update.json` 中的 SHA256 不是当前安装包的 SHA256。
- 客户端下载到的文件被缓存或被中断。

处理：

1. 重新生成 `update.json`。
2. 重新上传安装包和 `update.json`。
3. 用 `sha256sum` 验证远端文件。
